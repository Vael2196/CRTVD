# Frozen image references

`input-scene.png` is owned procedural artwork made by
`node scripts/create-fixtures.mjs`: colour gradients, checker pixels, diagonals,
a circle and a transparency ramp. The larger benchmark input is generated by
the same formula. `input-photo.jpg` is an RGB JPEG encoding of the small scene,
created with Pillow at quality 92, for CLI codec coverage.

The three output PNGs are frozen visual baselines generated by the native CLI
with the options in cases.json. Normal tests read these files and never replace
them. Both native and Wasm results are compared with them. Alpha must be exact;
at most 0.5% of pixels may have an RGB channel difference greater than 2. This
tolerance accommodates floating-point ties across toolchains while rejecting
large processing changes. A failed comparison writes a magenta/black difference
image under test-results/references/.

To intentionally change a baseline, build the native CLI, run
`npm run references:update`, inspect every changed PNG, then commit both the
images and manifest. Do not use this command merely to silence a failing test.

Input SHA-256 and reference names are recorded in manifest.json. All procedural
fixtures and their outputs are distributed under the project's MIT licence.
